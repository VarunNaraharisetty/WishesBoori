# Happy Birthday, Varshini (Boori) 💗

An interactive 8-screen birthday website with the original photos plus four additional photos.

## Files
- `index.html`
- `style.css`
- `script.js`
- `images/` — `memory-1.jpg` through `memory-9.jpg`

## Upload to GitHub Pages
1. Extract this ZIP.
2. Upload the files and the complete `images` folder to the root of your GitHub repository.
3. Commit the changes to your publishing branch.
4. In Settings → Pages, select the correct branch and `/(root)`.
5. Refresh the published page with Ctrl + Shift + R.

Keep filenames and folder structure unchanged. The first three photos are used in the memory-lane opening; the six tiles use the other six photos, so the photos are not repeated across those sections.
